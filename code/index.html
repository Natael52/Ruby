Comment le programme a fonctionné

J'ai crée une fonction pour chaque dessin unicode. J'ai utilisé des additions et multiplications pour afficher un nombre de fois de caractères. J'ai aussi programmé des variables. J'ai changé le nombre d'espaces ainsi de caractères avec des opérations. J'ai mis toute une ligne dans "print()". J'ai utilisé des boucles avec les opérations. J'ai aussi utilisé des variables dans la commande "print()".

Difficultés

J'ai des difficultés pour le sapin pour afficher les boules de Noël aléatoires. Mais j'ai réussi à créer parfaitement les autres formes. Et j'ai entré le chemin d'accès d'une image dans l'exercice avec Pillow, il me donnait une erreur que c'était invalide.
